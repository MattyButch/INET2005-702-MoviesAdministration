### Intro ###
This is a project that I am developing as part of a Web Application Programming course for my second year of IT Programming at NSCC. 

This project is a movie review site inspired by RottenTomatoes.com, with the intention of enabling users to search for, browse, and review movies pulled from a database. 

 

### Architecture ###
The architecture will consist of

- A public facing user website with full functionality and professional looking UI that reads data from an API.
- An API that pulls movie data from a SQL Server based database.
- An administrative website with CRUD functionality with the SQL Server.


### Technology ###

- ASP.NET Core MVC
- SQL Server
- ASP.NET Core Web API
- React
